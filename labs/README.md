# Labs

Phase 3 runs weeks 16–18 and ends with Capstone 2. Each lab has a goal, a brief, concepts, steps naming files and TODOs, a check, evidence and a stretch task. You need a working fde-02 checkout (Capstone 1) as the system under test.

| Week | Lab | Exercises |
| --- | --- | --- |
| 16 | [Golden sets and metrics](week-16-golden-sets-and-metrics/README.md) | `token_f1`, `citation_scores`, `wilson_interval` |
| 17 | [Judges and calibration](week-17-judges-and-calibration/README.md) | `build_judge_messages`, `perturb_number`, `cohens_kappa` |
| 18 | [Red team, gate and release memo](week-18-redteam-and-release-gate/README.md) | `detect_pii`, `bootstrap_diff_ci`, `check_gate`, results table |

`make exercises` lists what is left. The starter's `make test` and CI skip exercise tests, so your build stays green while you work.
